# Audio
-Panzera Free Audio Extractor. Useful to extract audio from a video.
See: https://www.videohelp.com/software/Pazera-Free-Audio-Extractor

# Data
- TestDisk. Recover deleted files. Generally works for most situations.
See: https://www.cgsecurity.org/wiki/TestDisk_Download
- DMDE. Commercial data recovery software that works when TestDisk doesn't. Well worth the money when it is required.
See: https://dmde.com/

# Source Control
- DeepGit. "DeepGit is a tool to investigate the history of source code. It is based on git blame and makes it easy to trace changes to a line or block of code. DeepGit will detect code movements, even if lines are not identical."
See: https://www.syntevo.com/deepgit/

# Video
- LosslessCut. Allows the user to export a selected portion of a video. It is non-destructive and relatively simple to use.
See: https://github.com/mifi/lossless-cut
