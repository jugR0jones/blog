# The idea

Colossal Cave Adventure was one of the first text-based adventure games, and it was originally written in Fortran. The idea behind this project is to use local AI to write a Fortran interpreter and a user interface for the game, allowing players to experience the classic adventure in a modern way.

This will tick off my personal goal of modernizing this classic game

The project is built using the Kilo Code harness, version 7.7.7, running the Qwen3-coder-next 80b parameter model.

# Progress

## Day 1: Initial setup and planning

A detailed plan was generated by the AI, outlining the steps needed to create a Fortran interpreter and a user interface for the Colossal Cave Adventure game. The plan includes:
- Researching the original Fortran code of Colossal Cave Adventure.
- Designing a Fortran interpreter that can execute the game's code.
- Creating a user interface that allows players to interact with the game.

If the game can be completed successfully by following the walkthrough then this project will be deemed a success.

The project structure was created and the dependencies were set up. The project can build successfully.

## Day 2: 

The Fortran interpreter was implemented, allowing the game to be executed. The user interface was also created, providing a way for players to interact with the game. 

In theory the game can be played through at this stage; however, the AI keeps running into issues with the dependencies and build system.

Feeling brave, I let the model take care of its problems. SDL was downloaded again and the files placed in the appropriate location inside the project.

ImGUI required a number of iterations to get it working correctly, but eventually the model was able to get it to build and run.
